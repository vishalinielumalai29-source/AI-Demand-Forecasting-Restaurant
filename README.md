 🍽️ AI-Based Demand Forecasting & Inventory Optimization for Restaurant

 📌 Problem Statement
Restaurants often struggle with predicting customer demand accurately, leading to:
- Food wastage due to overstocking
- Loss of sales due to understocking

This project aims to solve these issues using AI-based demand forecasting and smart inventory optimization.

---

 🎯 Objectives
- Predict future demand for food items
- Optimize inventory levels
- Reduce food wastage
- Improve operational efficiency

---

 📊 Dataset
- Dataset used: `demand_forecasting.csv`
- Contains historical data such as:
  - Orders
  - Sales trends
  - Demand patterns

📁 Dataset is included in this repository.

---

 🧠 Methodology

 1. Data Preprocessing
- Handling missing values
- Data cleaning
- Feature selection

 2. Exploratory Data Analysis (EDA)
- Trend analysis
- Demand patterns visualization

 3. Model Building
- Machine Learning model for forecasting
- Training and testing using historical data

 4. Inventory Optimization
- Predict demand
- Suggest optimal stock levels
